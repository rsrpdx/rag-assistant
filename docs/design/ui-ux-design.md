## 一、页面布局设计

### 1.1 全局布局框架

采用 **三态布局**，不依赖传统后台管理系统的固定侧边栏模式：

- 登录/注册：全屏居中卡片，无导航干扰
- 首页：搜索栏居中 + 功能入口卡片 + 三栏内容区
- 聊天页：左窄栏(240px) + 右侧全高对话区
- 知识库管理：顶部导航 + 全屏卡片网格
- 个人中心：居中卡片，最小信息密度

## 二、色彩方案

### 2.1 主色板

| Token | 色值 | 用途 |
|-------|------|------|
| 品牌色 | #6366F1 (Indigo-500) | 按钮、链接、激活态 |
| 辅助色 | #818CF8 (Indigo-400) | hover态、渐变 |
| 强调色 | #4F46E5 (Indigo-600) | active态 |
| 成功 | #10B981 (Emerald-500) | 解析完成、成功提示 |
| 警告 | #F59E0B (Amber-500) | 警告提示 |
| 错误 | #EF4444 (Red-500) | 错误提示 |

### 2.2 暗色模式（默认）

| Token | 色值 | 用途 |
|-------|------|------|
| bg-primary | #0A0A0A | 页面最底层 |
| bg-secondary | #111111 | 卡片/面板背景 |
| bg-tertiary | #1A1A1A | 可交互组件背景 |
| bg-elevated | #222222 | 输入框/分割线 |
| text-primary | #FFFFFF (87%) | 一级信息 |
| text-secondary | #A1A1AA | 二级信息 |
| text-tertiary | #52525B | 占位/禁用 |
| border | #27272A | 边框 |
| border-hover | #3F3F46 | hover时边框 |
